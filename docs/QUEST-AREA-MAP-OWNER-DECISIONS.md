# Quest-area map · owner decisions

Preserved owner-approved geographical map behavior from the retired progress/constellation design document. Progress is a layer on the Main Map; no independent constellation or star-chart UI is authorized.

Mapping takes priority, with Progress as an optional map layer. Start with the existing Quest Route entry points in the Velen hubs and walkthroughs. The map opens on the current walkthrough stop and fits its mapped, recommended activities. Include only activities explicitly associated with that quest in the guide. Use verified in-game geography, roads, crossings, and pin positions. A missing geography or location verification stays open. Use the road network and pins for player-directed planning. The map does not require a starting position, draw a suggested circuit, or infer a travel order. Tapping a linked pin opens its existing hub or page directly. Preserve the map view on Back.

Use the shared marker language and forged-seal art direction across main and quest-area maps. The first comparison will use Nilf, Bloody Baron, Hunting a Witch, and Funeral Pyres only where verified map data is available. Prior illustrated sketches are visual references for styling. Their road geometry and placements are not geographic evidence.
