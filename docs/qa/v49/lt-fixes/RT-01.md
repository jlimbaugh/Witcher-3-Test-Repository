# RT-01 · Region Tools global tiles: **PASS (fixed)**

*Author-supplied evidence (LT, implementer). Not independent. Headless Chrome (puppeteer-core), isolated `/tmp` profile per run, iPhone UA + touch emulation at 375×667, 390×844, 430×932, 852×393, 932×430, and desktop 1280×900 (mouse). **Not physical Safari.** "before" = PR #24 tip `cd6783ff628801a1f84b81064a3b74de4760c2a6` (dist identical to live v49 `ba59252`), "after" = this branch. Both served locally from the box (`python3 -m http.server`). Script: `evidence/scripts/rt01.cjs`. Raw data: `evidence/rt01.json`.*

**Finding (PR #25, `04-region-tools.md`):** Home, Regions, Field Reference, Progress and Constellation tiles all opened `#velen`, because `velen-r18.js` `link()` passes every `#…` href through `routeModel.sharedHash()`, which rewrites non-Velen hashes to `#velen`.

**Fix:** `regionTools()` now passes the five guide-wide navigation entries as `'index.html'+item.href`. `link()` already honours that prefix (it strips `index.html` and skips `sharedHash`), so the tiles keep their own destinations. Route maps and Merchants still go through `sharedHash` (`#velen/map`, `#velen/merchants`). No change to `velen-routing.js`. Cache tag `velen-r18.js?v=v49-lt-fixes-1`; seam pin updated with a history line in `slice2-nilf.test.cjs`. New unit test `v49-lt-fixes.test.cjs` › RT-01.

**Note:** Constellation's href is rewritten by the existing app link decorator to `#whiteorchard-constellation/whiteorchard`, the same page the wolf menu opens ("The Continent · Constellation"). Counted as PASS.
