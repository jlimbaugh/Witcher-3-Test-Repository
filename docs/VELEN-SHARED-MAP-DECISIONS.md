# Shared map decisions

The owner confirmed that Show on Map opens the same main map and controls as ordinary browsing. A task entry sets the initial camera on the viewed objective and opens at a close scale, with nearby tasks visible. The first iPhone review starts at the Inn at the Crossroads.

| # | Decision | Approved behavior |
|---|---|---|
| 1 | Task button | Show on Map. |
| 2 | Placement | Next to the viewed objective’s actions. |
| 3 | Initial location | Center on the walkthrough step being viewed. |
| 4 | Location uncertainty | Show the best verified area or region when a point is unavailable. |
| 5 | Opening zoom | Start at the 56 × 56 stamp scale, then allow movement. |
| 6 | Nearby activities | Show every mapped task inside the opening view. |
| 7 | Landmarks | Keep them visible with lower visual emphasis. |
| 8 | Crowded seals | Group markers that are too close to tap separately. Open a list on tap. |
| 9 | Symbol language | Use task-type seals with selected unique emblems. |
| 10 | Active objective | Add a silver rim to the existing symbol. |
| 11 | Marker selection | Tap a seal to reveal its name and page link. |
| 12 | Routes | Use terrain and seals. |
| 13 | Progress setting | Remember the last map-layer preference across entries. |
| 14 | Completion state | Dim completed seals and show a check with Progress on. |
| 15 | Completion action | Record progress on task pages. |
| 16 | Gestures | Drag and pinch on the map. Scroll the page outside it. |
| 17 | Controls | Keep Back, Layers, and Recenter visible. Expose accessible zoom buttons through Layers. |
| 18 | Recenter | Restore the initial camera and zoom. |
| 19 | Browsing after entry | Keep the viewed objective active while panning elsewhere. |
| 20 | Return trips | Restore camera and selection from a detour. Restore the viewed step and scroll from the map. |
| 21 | First pilot | Test the Nilfgaardian Connection Inn step, Funeral Pyres or At the Mercy of Strangers, and the return trip on iPhone. |

The first build uses the existing verified Velen terrain and registered pilot markers. The two road activities still share one approximate area. Expanding the map inventory and bringing other regions into the shared map follow the pilot.
