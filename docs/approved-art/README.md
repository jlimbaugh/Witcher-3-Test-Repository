# Phoenix default art

This folder is the source for the new default art moving forward. Preserve each region's illustrations and draw on White Orchard and Velen for shared treatments.

| Batch | Asset | State |
| --- | --- | --- |
| 1 | [Quest header frames](frames/README.md) | Six standalone reference designs. Inset art review is next. Test-page application is pending. |

Review one asset at a time, top to bottom. Review six standalone frames with empty openings. For an illustrated asset, review three inset-art options separately after the frame review. Keep frame and inset files independent.

After three assets are approved, mock them up together and apply them to the Nilf Inn test page. Check them in context before locking the tested treatments as implementation defaults. Prior studies remain available through the [art catalog](../ASSETS.md).
