# Phoenix default art

**Locked default for simple buttons.** Use the [six approved two-metal designs](simple-buttons/set-01-two-metal-review.webp) as the guide-wide material reference. Use brushed blue-gray steel for faces and structural rails, polished silver for raised ornament, and centered ivory labels. Keep the two metals visually distinct at phone size. The [original dark sheet](simple-buttons/set-01-review.webp) sets the darkest permitted treatment. The approved page reference below establishes placement.


This folder is the source for the new default art moving forward. Preserve each region's illustrations and draw on White Orchard and Velen for shared treatments.
